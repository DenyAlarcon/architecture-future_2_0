# Агрегаты

| Bounded context | Ключевые агрегаты | Границы и правила | Ключи |
| --- | --- | --- | --- |
| Пациентский поток | Пациент, запись на приём, визит | Визит нельзя завершить без записи. В события для аналитики не передаются медицинская карта и история болезни. | `patient_id`, `appointment_id`, `visit_id` |
| Финансовые сервисы | Кредитный договор, счёт, платёж | Счёт связан с услугой или визитом. Платёж не может быть больше остатка по счёту. | `credit_contract_id`, `invoice_id`, `payment_id` |
| ИИ-исследования | ИИ-исследование | Публикуется только статус, версия модели и агрегированный результат. Сырые медицинские данные не передаются в аналитику. | `ai_study_id`, `patient_id`, `model_version` |
| Новые направления | Фарма-партнёр, поставка, медоборудование | Данные принимаются только от зарегистрированного партнёра или устройства. Телеметрия связана с конкретным устройством. | `partner_id`, `supply_id`, `device_id` |
| Данные и аналитика | Набор данных, отчёт | Набор данных публикуется только при наличии владельца, описания схемы и проверки качества. Отчёт строится только по разрешённым наборам. | `dataset_id`, `report_id` |
| Доступ и аудит | Политика доступа, запрос доступа, событие аудита | Доступ проверяется по роли, домену и чувствительности данных. Каждый запрос к витрине пишет аудит. | `policy_id`, `access_request_id`, `audit_event_id` |
| Старые системы | Запись старого DWH, событие старой шины | Старые DWH и Camel используются только как источники на время миграции. Новая бизнес-логика туда не добавляется. | `legacy_record_id`, `legacy_event_id` |
