# Задание 3. Целевая архитектура и риски

## Артефакты

- `c4-architecture.puml` — C4-диаграмма, где показаны контейнеры целевой архитектуры и компоненты платформы данных.
- `risk-map.md` — карта архитектурных, организационных и технологических рисков.
- `risk-management-plan.md` — план управления рисками.

## Краткое описание решения

Целевая архитектура на горизонте трёх лет строится вокруг доменных сервисов, событийной платформы и Data Lakehouse.

Основные изменения:

- новые бизнес-направления подключаются как отдельные домены;
- домены обмениваются событиями через платформу событий;
- DWH SQL Server 2008 и Apache Camel остаются только как временные мосты совместимости;
- после вывода Apache Camel ФЛК, маршрутизация, ретраи и очередь ошибок переходят в сервисы интеграции и платформу событий;
- потоковые трансформации выполняются в сервисах интеграции, пакетные трансформации — в слое загрузки данных;
- бизнес-логика остаётся в доменных сервисах, а не в интеграционной шине;
- данные для аналитики публикуются как описанные наборы данных через каталог метаданных;
- портал самообслуживания строит отчёты только по разрешённым наборам данных;
- медицинские карты, истории болезни и результаты медицинских исследований не попадают в аналитическую витрину.

## Как открыть диаграмму

Файлы `.puml` можно открыть в PlantUML-совместимом редакторе или сгенерировать командой:

```bash
plantuml Task3Advanced/c4-architecture.puml
```
